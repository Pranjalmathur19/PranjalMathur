## 🚀 Getting Started

### Prerequisites

Make sure you have a C/C++ compiler installed, such as:
- [GCC](https://gcc.gnu.org/) (Linux/Mac)
- [MinGW](https://www.mingw-w64.org/) (Windows)

### Installation & Running

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. Compile the program
   ```bash
   g++ calculator.cpp -o calculator
   ```
   *(replace `calculator.cpp` with your actual filename)*

3. Run the program
   ```bash
   ./calculator
   ```

## 📖 Usage

Run the executable and follow the on-screen prompts to enter numbers and select an operation.

```
Enter first number: 10
Enter second number: 5
Choose an operation (+, -, *, /): +
Result: 15
```
